ChatGPT's web search reads Bing's index. That means the fastest way to get a newly published or freshly updated page in front of ChatGPT users isn't to wait for a crawl, it's to tell Bing about it directly, right now. IndexNow is the real-time indexing protocol that makes this possible: one ping and Bing re-crawls your page within minutes. The Found by AI IndexNow tool generates your API key, walks you through the one-time key-file setup, and lets you submit URLs instantly.

## Set up IndexNow

<Steps>
  <Step title="Go to the IndexNow tool">
    Navigate to [areyoufoundbyai.com/tools/indexnow](https://areyoufoundbyai.com/tools/indexnow). The tool generates a unique API key for your site, keep it, because the same key works forever for your domain.
  </Step>
  <Step title="Generate your API key">
    The tool generates a unique hexadecimal key (for example, `0a46923dd3164471a56d73e1714c07a2`). Copy it, you'll need it for both the key file and every submission request.
  </Step>
  <Step title="Host the key verification file">
    Create a plain-text file named `YOUR-KEY.txt` containing exactly your key as the sole content, no extra whitespace or newlines. Upload it so it's accessible at:

    ```
    https://yourdomain.com/YOUR-KEY.txt
    ```

    This file is how IndexNow verifies you own the domain. It ensures nobody can submit URLs on your behalf without your key file in place. This is a one-time step, once the file is live, you never need to touch it again.
  </Step>
  <Step title="Submit your URLs">
    Paste your list of URLs (one per line) into the submission field, or enter your sitemap URL and the tool will extract the URLs automatically. Click **Submit** and the tool pings Bing's IndexNow endpoint on your behalf. Bing re-crawls the submitted pages typically within minutes.
  </Step>
</Steps>

## What happens after you submit

Bing adds your submitted URLs to its priority crawl queue and re-indexes them in minutes rather than days. Because ChatGPT's web-search feature reads Bing's index, your updated content becomes available to ChatGPT users in its next retrieval cycle. IndexNow also notifies Seznam, Naver, and Yandex (all IndexNow-compliant engines) from the same single submission.

<Note>
  IndexNow only submits to Bing and other IndexNow-compliant engines (ChatGPT search, Seznam, Naver, Yandex). Google uses its own crawl pipeline and does not participate in IndexNow. Use Google Search Console's URL Inspection tool or a sitemap ping to accelerate Google indexing separately.
</Note>

## When to use IndexNow

Submit to IndexNow any time you make a change that should be discovered quickly:

- After publishing a new page or blog post
- After fixing or rewriting content for AI citability
- After adding or updating JSON-LD schema markup
- After creating or updating your `llms.txt` file
- After fixing a previously blocked AI crawler in `robots.txt`
- After launching a new product or service page

<Accordion title="How do I know the submission worked?">
  Bing returns an HTTP 200 response for successful submissions and a 422 for invalid requests. After submitting, you can verify re-indexing by searching Bing for `site:yourdomain.com/your-page-path` and checking the cached date, or by monitoring the page in Bing Webmaster Tools.
</Accordion>

<Tip>
  Make IndexNow submission the last step in your content publishing checklist, publish, add schema, update llms.txt, then ping Bing. Doing all three before submitting means Bing crawls the fully optimised version of the page on the first pass.
</Tip>
