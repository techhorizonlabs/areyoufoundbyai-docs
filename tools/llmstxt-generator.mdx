`llms.txt` is a plain Markdown file at the root of your domain that gives AI systems a short, structured guide to your site: what the business does and which pages matter. Are you found by AI? does not offer it as a separate tool page. It comes with the scan instead:

- **Free scan:** "A starter llms.txt in every free scan, written from your site."
- **Full report:** "The full report generates the complete file."

[Run the free scan](https://areyoufoundbyai.com/) to get your starter file. It is written from your own pages, not from a template.

<Note>
  There is no standalone llms.txt generator page on areyoufoundbyai.com. If you have an old bookmark to a generator URL, use the free scan instead.
</Note>

## The open-source route

If you would rather generate or check the file yourself, the open-source [thl-open](https://github.com/techhorizonlabs/thl-open) suite includes two ways to do it:

| Where | What it does |
|---|---|
| [`skills/geo-llmstxt`](https://github.com/techhorizonlabs/thl-open/tree/main/skills/geo-llmstxt) | A Claude Code skill that validates an existing `llms.txt` or generates a new one by crawling the site. The format rules and a fill-in template are in `references/spec.md`. |
| [`skills/geo/scripts/llmstxt_generator.py`](https://github.com/techhorizonlabs/thl-open/blob/main/skills/geo/scripts/llmstxt_generator.py) | A Python script with two modes, `validate` (the default) and `generate`, that prints its result as JSON. |

```bash
# Inside a clone of thl-open
pip install -r skills/geo/requirements.txt
python3 skills/geo/scripts/llmstxt_generator.py https://example.com validate
python3 skills/geo/scripts/llmstxt_generator.py https://example.com generate
```

From Claude Code, with the suite installed, you can also run `/geo llmstxt https://example.com`. See [Claude Code Skills](/guides/claude-code-skills) for installation.

## The llms.txt format

The format below follows the spec bundled with the `geo-llmstxt` skill. A valid file starts with an H1 title, then a one-line blockquote description, then at least one H2 section of page links:

```markdown
# Your Business Name

> One clear sentence: what your business does and who it serves.

## Docs

- [About](https://yourdomain.com/about): Company overview, founding story, and team.
- [Services](https://yourdomain.com/services): Full list of services with pricing overview.
- [Contact](https://yourdomain.com/contact): Phone, email, and office locations.

## Products

- [Product A](https://yourdomain.com/products/a): What it does, who it's for, and how it's priced.
- [Product B](https://yourdomain.com/products/b): What it does and how it differs from Product A.

## Key Facts

- Founded in YYYY by Founder Name
- Headquartered in City, Country
- Key products: Product A, Product B

## Contact

- Website: https://yourdomain.com
- Email: hello@yourdomain.com

## Optional

- [Full index](https://yourdomain.com/llms-full.txt)
```

Each page entry follows the pattern `- [Page Title](absolute-url): Brief factual description`. Descriptions should state what information is on the page, not marketing copy. Use full `https://` URLs, never relative paths. Keep the blockquote description under 200 characters.

## Where to host it

Publish the file at the root of your domain:

```
https://yourdomain.com/llms.txt
```

It should return HTTP 200 without a redirect. Most static-site generators and CMS platforms let you place files in a `public/` or `static/` root folder.

A longer companion file, `llms-full.txt`, can hold the complete page inventory with longer descriptions. Link it from the `## Optional` section of your main file.

<Accordion title="How often should I update llms.txt?">
  Update it whenever you add significant new pages, remove pages that are listed, or change key facts about your business. After updating, you can submit the `llms.txt` URL with the [IndexNow Submitter](/tools/indexnow) so Bing re-crawls the updated file.
</Accordion>

<Accordion title="Does llms.txt guarantee that AI will recommend me?">
  No. It helps machines understand your site, but a website change does not guarantee that an engine will recommend you. Measure the answers again after you publish it to see whether anything changed.
</Accordion>
