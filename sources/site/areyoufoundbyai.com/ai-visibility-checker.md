## What AI visibility means

AI visibility is whether AI assistants name your business when someone asks them for a recommendation in your category. It is different from search ranking. A search engine returns a list of links and the buyer chooses; an AI assistant usually returns one answer naming a few businesses, and the ones it leaves out are never seen. Visibility is measured by asking the engines real buyer questions and recording who gets named, how often, and which sources the answer leans on.

### Visibility is not the same as readiness

Readiness is whether your site is built so an engine can read and trust it: structured data, one consistent business name and address, pages that answer questions directly. Visibility is whether the engines actually name you today. A site can be technically ready and still invisible, which usually means the citation and mention work has not been done yet. This checker reports both.

Each question is asked more than once because engine answers vary between runs, and a single sample would be noise.
