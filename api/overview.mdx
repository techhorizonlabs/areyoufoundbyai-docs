The Found by AI REST API lets you trigger live AI-visibility scans programmatically, retrieve scores, and integrate results into your own tools, dashboards, and workflows. Every response is drawn from real-time queries to the AI engines — nothing is cached or estimated.

## Base URL

All API requests are made to:

```
https://areyoufoundbyai.com/api
```

## Authentication

Pass your API key as a Bearer token in the `Authorization` header:

```
Authorization: Bearer YOUR-API-KEY
```

The free tier requires no credentials at all — you can run your first scan with no setup. Paid tiers unlock more engines, more questions, and higher rate limits. Scoped keys for agency Fleet accounts are passed as part of the MCP endpoint URL rather than an `Authorization` header. See [Authentication](/api/authentication) for full details.

Content-type for all requests is `application/json`.

## Rate limits

| Tier | Limit |
|------|-------|
| Free | Up to 15 scans per browser per day; a server-wide queue may apply on very busy days |
| Monitoring ($79/mo) | Unaffected by the free-tier queue; weekly automated re-measurement included |

<Note>
  Paid tiers are never affected by the free-tier server-wide cap. Leave your email during a queued scan and your result arrives as soon as it clears.
</Note>

## Available endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/scan` | Trigger a new AI Visibility + AI Readiness scan for a given URL |

<Note>
  The API currently exposes the scan endpoint. Full read endpoints for scores, verbatim answers, and fix lists are available via the MCP server — see [MCP Tools](/mcp/tools).
</Note>

## Error format

All API errors return a JSON body with a human-readable message and a machine-readable code:

```json
{
  "error": "message",
  "code": "ERROR_CODE"
}
```

### Common error codes

| HTTP status | Code | Meaning |
|-------------|------|---------|
| `401` | `UNAUTHORIZED` | Missing or invalid API key |
| `403` | `FORBIDDEN` | Valid key, but not permitted for the requested domain (scoped keys only) |
| `422` | `INVALID_URL` | The `url` parameter is missing or malformed |
| `429` | `RATE_LIMITED` | Rate limit reached for your tier |
| `500` | `SCAN_ENGINE_ERROR` | The scan engine encountered an unexpected error |

<Tip>
  A `422` response usually means the URL is missing a scheme (`https://`) or points to a private/non-public address. Always pass a fully-qualified public URL.
</Tip>
